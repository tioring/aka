API 연동 가이드 — Real-data hookup

이 페이지는 기본적으로 시뮬레이션 데이터로 동작합니다. 실제 데이터에 연결하려면 <script>의 CONFIG 객체를 채워주세요.

CONFIG.apiKey · 서울 열린데이터광장의 실시간 도착정보 API 키
CONFIG.endpoint · 기본은 http://swopenapi.seoul.go.kr/api/subway/{key}/json/realtimeStationArrival/0/10/{station}

키가 비어 있거나 요청이 실패하면 자동으로 시뮬레이션 모드로 폴백합니다. 5분 세션이 끝나면 폴링을 자동 중단해 API 호출을 절약합니다.
