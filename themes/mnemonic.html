01 ↻
--resume / --continue

대화는 죽지 않는다.

터미널을 닫아도, 노트북을 끄고 카페를 옮겨도, 어제의 컨텍스트는 디스크에 남아 있다. 새 세션을 열기 전에 항상 먼저 묻기 — 이미 절반쯤 한 일이 있지 않은가?

# 마지막 세션 그대로 이어가기
claude --continue

# 과거 세션 골라서 부활
claude --resume
갈고리

"세션은 북마크다. 책을 닫아도 끼워둔 자리가 있다."

02 ⌘
.claude/skills/

스킬은 호출하지 않아도 온다.

슬래시 명령은 사용자가 부른다. 스킬은 작업의 냄새만 맡으면 알아서 발동된다. 디렉터리에 마크다운 한 장만 두면 끝 — 트리거 조건만 잘 적으면 모델이 스스로 켠다.

# 디렉터리만 만들면 된다
.claude/skills/refactor-react/
  └─ SKILL.md   # 트리거·절차·예시
갈고리

"슬래시는 벨, 스킬은 센서."

03 ⚙
settings.json · hooks

사람 없이 자동으로 켜져라.

PreToolUse, PostToolUse, Stop, SessionStart — 이벤트마다 셸 명령을 꽂을 수 있다. 매번 "테스트 돌려줘"라고 말하지 말고, Stop 훅에 박아두고 잊어라. 시스템이 너 대신 기억한다.

# settings.json 일부
"hooks": {
  "PostToolUse": [{
    "matcher": "Edit|Write",
    "command": "npm run lint --silent"
  }]
}
갈고리

"훅은 심장박동. 매 행동마다 자동으로 뛴다."

04 ⫶
subagent · Task tool

병렬은 3배 빠르다.

독립적인 탐색·검증을 메인 컨텍스트에 욱여넣지 마라. Explore·Plan·general-purpose 같은 서브에이전트에게 던지면 동시에 굴러간다. 메인 창의 토큰 예산을 보호하면서 결과만 받는다.

# 한 메시지에 여러 Agent 호출 = 병렬
Agent(Explore)  → 검색
Agent(Plan)     → 설계
Agent(Explore)  → 패턴 비교
                # 동시 실행
갈고리

"메인은 지휘자, 서브에이전트는 섹션. 같이 연주한다."

05 ⌬
MCP servers

도구는 외부에서 끌어온다.

GitHub, Cloudflare, Figma, 데이터베이스 — 다 MCP 서버다. 한 번 등록하면 슬래시 없이도 모델이 알아서 부른다. 코드를 바꾸지 말고 능력의 표면적만 바꿔라.

# 한 줄로 서버 추가
claude mcp add github \
  --command "npx @modelcontextprotocol/server-github"
갈고리

"MCP는 USB-C. 꽂으면 능력이 늘어난다."

06 /
.claude/commands/

반복은 한 번만 적는다.

매일 치는 프롬프트가 있다면 그건 이미 슬래시 명령이다. 마크다운 파일 하나로 박제하면, 다음부터는 `/이름`만 친다. 머리 속 단축어를 디스크 단축어로 옮기는 작업.

# 새 명령 만들기
.claude/commands/review.md

# 그 안에:
지금 브랜치의 변경을
보안·성능·가독성 순으로 점검해줘.
갈고리

"슬래시는 매크로. 한 번 잘 짜면 영원히 쓴다."

07 ↔
--remote / --teleport

웹과 터미널은 같은 작업이다.

집에서 터미널로 시작해, 출근길 모바일로 진행 상황을 보고, 회사에서 웹으로 마무리. 같은 세션이 클라우드와 로컬을 오간다. 컴퓨터를 옮긴 게 아니라 작업이 따라온다.

# 로컬 → 웹 클라우드로 이주
claude --remote

# 웹 세션 → 로컬 터미널로 회수
claude --teleport
갈고리

"세션은 여행 가방이다. 어디든 들고 간다."

일곱 개. 외울 만큼만.
