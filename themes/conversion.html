How it works

3단계, 10분이면 굴러갑니다.

YAML 한 장으로 정의하고, 깃허브에 올리고, 첫 루프가 도는 걸 지켜보세요.

i.

레포 연결

GitHub 앱 한 번 설치, 권한 범위 선택. 끝. 토큰 관리 없음.

ii.

에이전트 정의

.ralph/agents/*.yaml 한 장으로 트리거·모델·도구를 명세.

iii.

매일 받기

아침 7시에 PR이 떠 있고, 9시 미팅 전에 리뷰만 하면 됩니다.

FAQ

알고 싶은 것들.

못 찾는 답이 있다면 support@ralph.dev로.

이미 GitHub Actions가 있는데, Ralph가 다른가요?

Actions가 워크플로 실행기라면 Ralph는 에이전트의 일정과 상태를 책임지는 레이어입니다. Ralph는 Actions를 대체하지 않고, 그 위에서 에이전트의 컨텍스트·세션·재시도·관찰성을 관리합니다. 같이 씁니다.

코드를 외부 서버로 보내는 건가요?

실행은 격리된 단기 컨테이너에서 일어나며, 코드는 디스크에 영구 저장되지 않습니다. SOC 2 Type II·GDPR 준수, 시크릿은 KMS 암호화. 자세한 사항은 보안 백서에 있습니다.

모델은 무엇을 쓸 수 있나요?

Claude (Anthropic), GPT (OpenAI), Gemini (Google) — 작업 종류별로 다른 모델을 라우팅하도록 설정할 수 있습니다. 본인 API 키 BYOK 모드도 지원.

실패하면 어떻게 되나요?

지수 백오프 재시도, 3회 실패 시 워크플로 알림. 모든 실행 로그·토큰·중간 산출물이 보존되어 사후 디버깅이 가능합니다.

Pro에서 Solo로 다운그레이드 가능한가요?

네. 다음 빌링 사이클부터 적용되며, 잔여 일수만큼 비례 환불됩니다. 잠금 효과 없음.

오픈소스인가요?

코어 에이전트 SDK는 Apache 2.0 오픈소스, 매니지드 오케스트레이션이 유료 제품입니다. 셀프호스팅 옵션은 Team 플랜 이상.
