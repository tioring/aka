aka(1) — General Commands Manual
name
aka — open one-page design references in your browser, fast.
synopsis
aka [--list] [--cat=category] [--search=query] [theme]
description
aka is a tiny CLI front-end for the Atrium theme gallery. It opens a single design theme as a self-contained HTML preview in your default browser. It does not install anything, fetch over the network, or write to your home directory. Themes live in ./themes/.
options
-l, --list
List all themes registered in the gallery, grouped by category.
-c, --cat=category
Filter listing by category. Valid: curated · data · life · media · genre.
-s, --search=query
Substring search across name, description, and tags.
-o, --open=theme
Open the named theme in $BROWSER. Equivalent to passing the theme as a positional argument.
-r, --random
Open a random ready theme. Useful when you don't know what you want.
-v, --version
Print version and exit.
-h, --help
Print this help and exit.
